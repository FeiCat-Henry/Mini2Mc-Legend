双十一，一个小时

翻出两个尘封的 .so，抱着试试的心态发了过去。一小时后，46 个 region 全部变成了 .mca。

只留三行

技术部分，
就这三行。

寻址
每个区块的位置都被 16 个常量之一异或过；长度字段还会说谎，只有偏移是真的。
解压
载荷是原始 LZMA1，属性字节永远是 0x5D，字典 16 KB，末尾常差 1–4 字节。
结构
FlatBuffer 里 16 个段，每段 4096 个方块：低 12 位是 id，高 4 位是状态，下标 (y<<8)|(x<<4)|z。

完整的字段表和踩过的坑，写在 docs/r_format.md 里。页面这里不讲。

自己转一遍

三条命令，
把你的世界搬过来。

自检：拿一个 .r 样本，解码后回读比对
python tools/MiniWorld_R_Tool.py --selftest <存档目录>
全量转换：.r → .mca
python tools/to_mca.py --save <存档目录> --out out/world
俯视预览：看一眼再进游戏
python tools/render_map.py --save <存档目录> --dim m0 --out preview_m0.png

依赖只有一个，而且只有出预览图才用得到：pip install -r requirements.txt（Pillow）。转换本身只用标准库。没有原生窗口环境时，python tools/MiniWorld_R_Tool.py --web 会在本地起一个网页界面。映射表是 tools/mc_block_map.json，表里没有的方块一律落成土块。
